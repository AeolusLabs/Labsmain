# AeolusLabs visual system

Extends the existing company identity: midnight navy #0B1220, cyan #67E8F9, soft white #F8FAFC and slate surfaces. Space Grotesk display with Inter body. Angular A vector recreation of the user's selected top-left logo reference.

Shared header and footer on every route. Desktop links and a collapsible mobile navigation, visible keyboard focus and skip link. Headings use balanced text with a maximum 6rem scale. Wide content with generous vertical rhythm; services use text rows rather than repeated decorative cards.

Vib3Pulse uses a lime typographic product panel. This is branding treatment, not a screenshot. Client projects remain unpublished while permission is pending. Motion is limited to short hover feedback and smooth navigation; reduced-motion disables transitions and smooth scrolling.
